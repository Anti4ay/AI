# 07_AI / отчеты

> Журналы работы по AI-направлению: ежедневные и еженедельные планы/отчёты.

---

## Структура

```
отчеты/
├── README.md
├── ежедневные/                # формат имени: DD.MM.YY/
│   └── DD.MM.YY/
│       ├── DD.MM.YY.md
│       └── DD.MM.YY.html
└── еженедельные/              # формат имени: YYYY-MM-DD - YYYY-MM-DD/
    └── YYYY-MM-DD - YYYY-MM-DD/
        ├── План/{План.md, План.html}
        └── Отчет/{Отчет.md, Отчет.html}
```

---

## Ежедневные

**Когда вести:** каждый день, когда есть прогресс по AI-направлению (свой курс, изучение AI-Native, кастдэвы, разработка платформы).

**Формат:** подпапка `DD.MM.YY/` с `DD.MM.YY.md` (исходник) и `DD.MM.YY.html` (стиль Humble · Precise White Lab).

**Содержимое:** что сделано, что в работе, блокеры, план на завтра. По исполнителям (Никита / Гоша / Антон / ...).

## Еженедельные

**Когда вести:** в конце каждой недели — План на новую неделю + Отчёт за прошедшую.

**Формат:** подпапка `YYYY-MM-DD - YYYY-MM-DD/` (диапазон через тире). Внутри — по два MD+HTML в подпапках `План/` и `Отчет/` (раскладка скила humble-html).

**Содержимое:**
- **План** — список задач недели: заголовок + Ответственный + Срок (+ описание).
- **Отчёт** — те же задачи + поле «Результат».
