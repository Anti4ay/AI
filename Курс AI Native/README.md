# Курс AI Native

**Источник:** курс конкурентов (стоимость $2000), доступ выдан для изучения.
**Цель изучения:** разбор технической базы для собственного курса AI/Cursor; конкурентный анализ.
**Статус:** в процессе изучения.

> Не путать с папкой [`../Курс по ИИ за 2к евро/`](../Курс%20по%20ИИ%20за%202к%20евро/) — это другой курс.

## Что хранить здесь

- Конспекты и выжимки после изучения уроков
- Отчёты по просмотру (что смотрел, что понравилось / не понравилось)
- Идеи и инсайты для собственного курса
- Материалы курса (если выгружаем)

## Структура

| Папка | Что внутри |
|-------|-----------|
| [Отчеты_просмотра/](Отчеты_просмотра/) | Дневник просмотра: дата, что смотрел, плюсы/минусы, инсайты |
| [Заметки_по_модулям/](Заметки_по_модулям/) | Конспекты по модулям/урокам курса |
| [Материалы_курса/](Материалы_курса/) | Исходники: ссылки, файлы, скрины, выгрузки |

## Шаблон отчёта по просмотру

Создавать файл вида `Отчеты_просмотра/YYYY-MM-DD_тема.md`:

```markdown
# Просмотр: <тема урока/модуля>

**Дата:** YYYY-MM-DD
**Длительность:** Xч Y мин
**Модуль/урок:** <название>

## Что смотрел
-

## Понравилось / сильные стороны
-

## Не понравилось / слабые стороны
-

## Инсайты для собственного курса
-

## Идеи / TODO
-
```
