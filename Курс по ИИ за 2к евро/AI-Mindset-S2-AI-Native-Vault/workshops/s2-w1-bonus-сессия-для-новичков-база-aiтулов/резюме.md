# Сессия для новичков: база AI-тулов

## Video
[![Сессия для новичков: база AI-тулов](https://img.youtube.com/vi/D23tyeI2R5I/maxresdefault.jpg)](https://youtube.com/watch?v=D23tyeI2R5I)

## Summary
Бонусная сессия первой недели AI-Native Sprint S2 была целиком посвящена базовому сетапу для новичков. Александр Поваляев начал со сбора вопросов участников — память агентов, naming convention, мультиагентная оркестрация, уровни доступа — и затем перешёл к живой демонстрации. Он создал vault с нуля из транскрипта вчерашней лекции Лисовского: запустил Claude Code в пустой папке, скормил ему файлы, попросил структурировать контент по naming convention и разложить по папкам. Параллельно открыл второй терминал с Claude и запустил в нём deep research по теме мультиагентности — показав на практике, как два агента работают одновременно над разными задачами в одном vault.

Антон Воскобович дал сжатый и доступный рассказ о том, что Obsidian vault — это просто папка на диске с markdown-файлами, без привязки к облаку и без vendor lock-in. Он продемонстрировал, как один и тот же файл виден одновременно в Obsidian и в Finder, показал markdown-разметку, frontmatter, ссылки между заметками через двойные скобки и бэклинки. Затем кратко прошёлся по ключевым плагинам: backlinks, Canvas, Command Palette, Daily Notes, Switcher, синхронизация (Obsidian Sync, Dropbox, Git).

Станислав Федосеев провёл концептуальный доклад «От Obsidian к Агентам и Personal OS». Начал с фундамента: LLM — это статичный алгоритм, который получает текст на вход и выдаёт текст на выход, токен за токеном. «Моего Claude не существует» — есть общий Claude, который становится «моим» только потому, что загружает мой контекст (CLAUDE.md, скиллы, файлы) в контекстное окно при каждом запросе. Через метафору фильма «Memento» Нолана — герой Леонард с антероградной амнезией ведёт расследование через записки и татуировки — Федосеев объяснил пять принципов: если не записано, агент не знает; если результат не сохранён, задачи не существует; если нет описания, где искать — агент не найдёт; если информация искажена — ответ будет искажённым; скиллы — это просто текст, сохранённый промпт. Определил POS как «контекст + автоматизации + агенты», ввёл понятие «контекстного гэпа» в компаниях (данные в CRM — менее 50% реальных знаний, остальное в головах и чатах) и описал автоматизацию как LEGO-блок: триггер → данные → трансформация → данные.

## Quotes
> "Моего Claude не существует. Есть только общий Claude — Opus 4.6 сейчас, потом будет какой-нибудь 4.7 или 5.0. Он становится моим только в момент ответа, потому что это написано в контексте."
> — Станислав Федосеев

> "Если информация не записана — ваш AI этого не знает. Если результат не сохранён — задачи не существует."
> — Станислав Федосеев

> "Правила важнее скиллов. Скиллы умрут, потому что умрёт Claude Code, и заменит его другая абстракция. А правила, которые я прописал для себя — они независимы от того, кем ты их вызываешь."
> — Александр Поваляев
