# W3: AI × Инвестиции и стратегия

## Video
[![W3: AI × Инвестиции и стратегия](https://img.youtube.com/vi/YL81FSHxdrg/maxresdefault.jpg)](https://youtube.com/watch?v=YL81FSHxdrg)

## Summary
**Евгений Рид** — инвестор и автор канала «Рид. Сознание и Инвестиции», 12 лет в технологических стартапах, последние 5 лет управляет собственным капиталом — показал, как он превратил Claude Code в **полноценный инвестиционный терминал**, заменяющий Bloomberg за $30 000/год. Главный тезис: **ручная торговля мертва**, но и «волшебный AI-чат про финансы» — это путь к убыткам; нужен микс из качественных данных, детерминированного кода и узко заточенных AI-агентов.

Женя продемонстрировал свой setup в Zed: специальная сборка Claude Code с кастомными плагинами для **TradingView** (через Electron-обёртку с computer vision) и **Interactive Brokers** (прямой API). Агент в реальном времени перестраивает графики, добавляет индикаторы, подтягивает баланс портфеля и читает текущие позиции. Управление полностью голосовое из терминала. Параллельно работает отдельный плагин для **macro-анализа** — агент с базовым промптом, построенным на современных научных работах по макроэкономике, который собирает индикаторы и выдаёт отчёт уровня инвестбанка.

Ключевая методология построения плагинов: **берёте список книг с сайта Стэнфорда → Claude извлекает структурированные знания → формирует промпт базового агента → нарезаете на отдельные skills** (portfolio rebalancing, report, statistics, risk metrics). Принципиально — никаких «закинул портфель в чат, дай анализ»: только детерминированный код, который анализирует портфель по понятным правилам.

Отдельно показан **криптопроект** на ~20 источниках данных (Nansen, CoinGlass, Bybit, Deribit, Binance) с трёхслойной архитектурой: macro context → market structure (модель FCI) → features layer с расчётом ускорения индикаторов. Поверх — **pipeline из агентов на Claude Code** для генерации торговых стратегий: hypothesis agent → research validator → tech writer → developer → paper trading → live trading → analyst, который записывает в общую память «эта стратегия мертва, не возвращайтесь». За 5 месяцев и ~100 протестированных стратегий получилось **2 рабочих** на Polymarket — низколиквидных, но с Sharpe ~9.

**Безопасность** агентов решена жёстко: интернет есть только у одного агента-исследователя в Docker-контейнере, и тот пропускает результаты через sanitizer (вырезает emoji, base64 и прочие prompt injection). Финальные стратегии переносятся руками на отдельный сервер без AI-агентов. Отдельный сильный совет — **писать инструменты самому, а не брать с GitHub**: Claude читает чужой код и пишет аналог по ТЗ, чтобы исключить зашитые закладки.

**Ключевой вывод:** AI в инвестициях работает только когда вы строите систему сами — учитесь экономике параллельно с тем, как «коучите» свою систему становиться умнее вместе с вами. Ленивый промпт в ChatGPT даст вам среднее арифметическое мнение и убытки.

## Tools
- [[Claude Code]] — основной интерфейс для всего setup; кастомная сборка с отдельным проектом «финансы» и набором плагинов
- [[Zed]] — редактор, в котором запускается Claude Code; выбран потому что ест меньше памяти, чем Cursor
- [[TradingView]] — основной источник графиков и индикаторов; подключен через Electron-обёртку, агент работает через computer vision
- [[Interactive Brokers]] — брокер для прямого API-доступа к портфелю, балансам, позициям; покрывает большую часть данных Bloomberg
- [[Codex (GPT-5 / GPT-4 extra high thinking)]] — модель, на которой написан crypto data pipeline; смог повторить докторскую диссертацию по CY-Trend
- [[Nansen]] — on-chain аналитика, перемещение ликвидности на/с DEX
- [[CoinGlass]] — фьючерсные данные, open interest, funding rates
- [[Bybit]] — биржа, источник тиковых данных для крипто-пайплайна
- [[Deribit]] — основная биржа для крипто-опционов
- [[Binance]] — основной источник level 1/2/3 тиковых данных для микроструктурных моделей
- [[Polymarket]] — площадка predictions, на которой работают live-стратегии Жени; latency ~274 ms
- [[Kalshi]] — второй prediction market, latency 38 ms; используется для арбитража
- [[Nautilus Trader]] — open-source движок для backtesting стратегий
- [[Cloudflare Tunnel]] — для удалённого доступа к локальному терминалу с телефона через Claude mobile app
