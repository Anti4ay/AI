## Summary
Валерий Ковальский — Head of AI в Red Mad Robot, автор sgr agent core (1100+ stars на GitHub), DevOps-инженер с сертификатами Cisco и опытом в провайдерской инфраструктуре. За год — более 2000 коммитов на GitHub, запуск нескольких вайбкод-сервисов (OwnClaw, поисковый бот по Telegram-каналам, база MCP-серверов).

**Эволюция к harness engineering:** Валерий начал с исторического обзора — от prompt engineering (2022-2023) через context engineering (конец 2025) к harness engineering. Ключевой тезис: более 50% того, что делает модели «умными» — это инженерная обвязка (tool calling, memory, context compression, sandboxing), а не сама модель. Claude Code — это полмиллиона строк кода, решающих задачу агентного харнеса. Каждый харнес заточен под свою модель: Claude Code — под Anthropic, Codex — под OpenAI, Open Code — универсальный.

**Экономика локального инференса vs подписки:** Развернуть Qwen 2.5 на собственном GPU-сервере стоит 55-77 млн руб/год, и хватит на 10-15 одновременных пользователей. Подписка за $200/мес — «как Spotify вместо собственной студии звукозаписи». Вывод: если у вас не банк с 500 разработчиками и секретными данными — берите подписку.

**Live build EverydayDash:** В реальном времени Валерий собирал дашборд с погодой, почтой, календарём, маршрутами и новостями. Арендовал VPS на Timeweb при участниках (1920 руб/мес), запустил двух параллельных агентов — один на бэкенд (Docker + API + тесты), второй на фронтенд (React + Tailwind). Третий агент занимался security-аудитом сервера. За время воркшопа получился рабочий сервис с авторизацией, API, адаптивной мобильной версией и AI-чатом.

**Безопасность и VPN:** Подробный разбор работы интернета, IP-адресов, DNS и VPN на уровне сетевых протоколов. Валерий объяснил, почему массовые VPN блокируют — Anthropic видит тысячи пользователей с одного IP. Рекомендация: собственный VPN-сервер, который никому не отдавать. История с блокировками аккаунтов: при бане компрометируются устройство, карта и IP.

**Деплой:** Регистрация домена (reg.ru), DNS через Cloudflare (бесплатно), Traefik как reverse proxy с автоматическими HTTPS-сертификатами. Альтернативы для упрощения — Dokploy, Coolify, GitHub Pages для статики.

**Три совета для вайбкодеров:** 1) Научитесь читать логи и stacktrace — это как учиться читать на другом языке, 2) Поймите основы интернета — DNS, IP, сети, 3) Прокачивайте коммуникацию — умение задавать вопросы определяет качество ответов, от людей и от LLM.

## Homework
- [ ] **A1 (базовый):** Арендуйте VPS (Timeweb/Hetzner), подключите к нему Claude Code через SSH и разверните простой проект (статический сайт или API) с Docker Compose. Настройте CLAUDE.md с описанием проекта (~1 ч)
- [ ] **A2 (средний):** Склонируйте EverydayDash (github.com/vakovalskii/EverydayDash), разверните на своём VPS с Traefik, настройте домен через Cloudflare с HTTPS-сертификатом. Запустите два параллельных агента — один на бэкенд, другой на фронтенд (~2-3 ч)
- [ ] **A3 (продвинутый):** Постройте собственный дашборд-сервис по шаблону EverydayDash: подключите 3+ API (погода, календарь, почта), настройте Docker Compose, Traefik, мониторинг в Grafana. Документируйте всё в /docs + CLAUDE.md (~4-6 ч)
