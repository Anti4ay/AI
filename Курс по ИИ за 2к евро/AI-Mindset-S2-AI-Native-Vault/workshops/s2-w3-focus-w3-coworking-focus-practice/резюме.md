# W3: Coworking + Focus Practice

## Video

## Summary
**Денис Смирнов** провёл практическую coworking-сессию о том, как превращать сырые персональные и бизнес-данные в **рабочий контекст для AI-агента**. Главный тезис: **не все данные являются контекстом** — между сырьём и агентом должна стоять чёткая инженерная цепочка из шести шагов, иначе агент будет уверенно генерировать ошибки.

В первой части участники поделились своими кейсами: **Алексей** собрал пять коннекторов для финансового ассистента сети ресторанов (банк через Stripe-коннектор, бухгалтерия Fakturownia, Kipper-касса) и упёрся в нормализацию; **Андрей** свёл около **10 000 файлов** из Telegram, ChatGPT и Apple Notes в Obsidian и не понимает, что с этим теперь делать; **Никита** решил не идти «снизу вверх» и поручил настройку OpenCode другому Claude Code как ассистенту.

Денис разобрал **шестишаговый pipeline**: источник → экстракция → нормализация → сохранение сырья → индексация → агент. Ключевые принципы: **сырые данные хранить всегда** (приватный GitHub/GitLab), потому что без них нельзя ни откатить ошибку, ни перестроить схему; **схема данных должна быть жёстко зафиксирована** в моменте, но эволюционировать вместе с пользователем; **агент — это последний слой**, тупой потребитель готовой информации, а не инструмент её структурирования.

Отдельно обсудили проблему **дедупликации сущностей**: один человек приходит как «Назар Петров» из Gmail, «Назар П» из Telegram и «user1567» из транскриптов — LLM физически не может это связать без вашей ручной карточки. Появилась **развёрнутая дискуссия** между Никитой, Стасом и Денисом о том, существуют ли «универсальные принципы построения структуры» или каждый строит свою — сошлись на том, что система должна функционально подчиняться задачам и эволюционировать.

**Ключевой вывод:** качество данных важнее экономии времени на разборе. Сужайте пространство для ошибки агента любыми способами.

## Tools
- [[OpenCode]] — open-source CLI-агент, альтернатива Claude Code; Никита настраивает свой OpenCode с помощью Claude Code как ассистента
- [[Claude Code]] — Anthropic CLI-агент, который Никита использует для настройки своей операционной системы поверх OpenCode
- [[Obsidian]] — инструмент для структурирования собственной системы знаний; Денис подчёркивает, что Obsidian позволяет работать с сетью смыслов, а не только с файлами
- [[SQLite]] — лёгкая локальная база, которую Алексей использует для агрегации финансовых коннекторов
- [[Fakturownia]] — польская бухгалтерская программа, через которую Алексей подключает банковские фактуры
- [[Stripe]] — payment-коннектор, через который Алексей собирает фактуры расходов в обход прямого open banking
- [[Kipper]] — кассовый аппарат / POS-система, через которую идут данные о доходах ресторанной сети
- [[LightRAG]] — фреймворк для извлечения сущностей из неструктурированного контента; работает плохо на персонально-специфических данных
- [[Granola]] — транскрибатор звонков с шаблонами для нормализации; Денис использует его как пример персонального pipeline (raw transcript → normalized template → context folder)
- [[Google Model Armor]] — система защиты от prompt injection на уровне API: запросы роутятся через неё до того, как попасть в LLM
- [[GitHub / GitLab / Яндекс GitHub]] — рекомендованные приватные репозитории для хранения сырых данных
- [[Telethon]] — Python-библиотека для Telegram User API; Андрей упёрся в то, что для агента нужно отдавать сессию реального аккаунта

## Homework
- [ ] **A1 (базовый):** Возьмите структурированный источник (Notion / Trello / Gmail) — пройдите путь от забора данных до нормализации. Ответьте на 5 вопросов ниже (~30 мин)
- [ ] **A2 (средний):** Добавьте сложный источник (Telegram / Rocket.Chat / WhatsApp) — зафиксируйте ограничения: права, история, форматы. Сохраните сырьё → поймите структуру → только потом индексируйте (~1-2 ч)
- [ ] **A3 (продвинутый):** Разложите оба источника честно по полной схеме из [презентации (слайд 7)](https://ai-mindset-2.algobasilisk.xyz/#slide-7) и постройте свою прослойку для агента (~3-4 ч)
- [ ] **Брать первым** — структурированный источник
- [ ] **Не делать** — не пытаться сразу «засунуть всё в агента»
- [ ] **Фиксировать** — ошибки, права, тупики, странные форматы
