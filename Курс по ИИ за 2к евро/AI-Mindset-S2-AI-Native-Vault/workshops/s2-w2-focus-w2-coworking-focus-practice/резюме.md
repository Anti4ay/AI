# W2: Coworking + Focus Practice

## Video
[![W2: Coworking + Focus Practice](https://img.youtube.com/vi/3LSYk6zzqpY/maxresdefault.jpg)](https://youtube.com/watch?v=3LSYk6zzqpY)

## Summary
Практическая сессия коворкинга, построенная на материале вчерашней лекции Степана Гершуни о 6 слоях AI-native архитектуры. Александр Поваляев подготовил интерактивную презентацию с промтами для каждого слоя и визуальный конструктор пайплайнов.

**Формат сессии** — обсуждение целей (15 мин), затем помидоро-сессии по 25 минут фокусированной работы. Участники выбирали свои направления и работали параллельно, периодически делясь прогрессом.

**Участники поделились целями:** Никита Астапов переносил Claude Code на сервер с двойной синхронизацией Obsidian и интеграцией через tmux + Telegram. Дмитрий Петровский работал над архитектурой звонков — именование, валидация транскрибации, мэтчинг аудио с текстом. Сергей начал домашнее задание Степана — построение архитектуры с MCP-коннекторами и субагентами.

**Александр показал** свой проект «Shepherd» — личный PM-агент, который подтягивает задачи из Linear и Obsidian, видит календарь звонков, актуализирует контекст из транскриптов и «гавкает» на владельца, напоминая о приоритетах. Также продемонстрировал командный дашборд AI Mindset с встроенным Claude-ботом.

**Ключевой вывод:** не устанавливать инструменты, а сначала описать архитектуру концептуально. Промты из презентации помогают задать правильные вопросы модели под конкретный контекст компании — это ценнее, чем готовые решения от спикеров.

## Homework
- [ ] **A1 (базовый):** Пройти интерактивную презентацию Focus Practice Deck и выбрать 1-2 слоя архитектуры, наиболее релевантных для своей компании (~30 мин)
- [ ] **A2 (средний):** Описать архитектуру одного бизнес-процесса через 6 слоёв, используя промты из презентации. Результат — текстовое описание или визуальная схема (~1-2 ч)
