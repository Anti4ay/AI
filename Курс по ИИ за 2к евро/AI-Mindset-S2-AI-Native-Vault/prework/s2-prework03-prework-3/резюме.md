## Summary
**Главный тезис: POS — это не набор инструментов, а архитектура принципов из 7 слоёв.** Хабаров представил модель: (1) Оператор (человек с контекстом), (2) Стратегия (общение с лучшей моделью), (3) Долгая память (правила, устав, история итераций), (4) Координация (спринты, GitHub Projects, Linear), (5) Правила (ограничения), (6) Рабочая среда (терминал, Codex, VS Code — агностично), (7) Исполнение + артефакт. Ключевая мысль: начинать сверху (стратегия, контекст), а не снизу (инструменты).

**Скиллы: создание и верификация** — развёрнутая дискуссия. Поваляев: скилл — это роутер, создаётся из опыта прохождения реальных процессов. Хабаров: два полюса — писать с нуля по гайдлайнам Anthropic или брать из авторитетных источников (Карпатый, официальные библиотеки). Середина (100 тысяч скиллов на маркетплейсах) бесполезна. Отдельная тема — скилл-экстрактор: через запись разговора с экспертом система извлекает знания в переиспользуемые инструкции.

**Codex (OpenAI) как инструмент автономной работы:** Хабаров показал, как Codex проработал 9 часов над проектом — собрал приложение на Electron для переформатирования стримов в Reels. Техника plan.md + status.md: план фиксирует атомарные задачи, статус хранит текущий прогресс. Codex эффективнее сжимает контекст при приближении к лимиту.

**Live-практика:** создание Telegram-группы, бота через BotFather, подключение OpenClaw с мозгом через OpenRouter (модель Kimi — $1/мес). Каждый тред в группе — изолированный контекст. Хабаров запустил установку OpenClaw через Codex в прямом эфире.

**Ключевой вывод:** не делайте автоматизацию ради автоматизации. Начинайте с маленького шага, сделайте плохо — и итерируйте.
