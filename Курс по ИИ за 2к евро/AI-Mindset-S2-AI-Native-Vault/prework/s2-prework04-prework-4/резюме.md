# Prework #4 — OpenClaw как проектный менеджер в Telegram

## Summary
Архитектура персональной операционной системы через призму **семи слоёв**: оператор, стратегия, долгая память, координация, правила, рабочая среда и исполнение. Серёжа Рис провёл live-демо настройки **OpenClaw** как Telegram-бота с интеграцией GitHub Issues, показал технику долгой автономной работы агента через файлы **plan.md** и **status.md**, объяснил механизм **компактизации контекста** в Codex и почему он превосходит Claude Code для многочасовых задач.

Практическая часть включала пошаговое создание Telegram-группы с ботом, подключение LLM через OpenRouter (модель Kimi), настройку тредов с изолированным контекстом и **метод супервизора** — когда Codex/Claude Code настраивает OpenClaw, а не OpenClaw настраивает сам себя.
