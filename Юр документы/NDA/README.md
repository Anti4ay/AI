# NDA — ООО «СтроимВместе»

> Соглашение о конфиденциальности для входа в проект с ООО «СтроимВместе» (Иваново). Сторона с нашей стороны — ИП Орешкин А.В., команда работает под его ответственностью и поимённо не раскрывается.

## Файлы

| Файл | Что это |
|------|---------|
| `NDA_СтроимВместе_ИП_Орешкин.pdf` | Готово к отправке и подписи, 6 страниц |
| `NDA_СтроимВместе_ИП_Орешкин.docx` | Если компания попросит правки в Word |
| `NDA_СтроимВместе_ИП_Орешкин.md` | Текст для чтения и правок в редакторе |
| `content.js` | Единственный источник текста |
| `build.js` | Сборка `.docx` и `.md` из `content.js` |

Текст правится **только** в `content.js`, `.md` и `.docx` из него собираются, поэтому разойтись не могут:

```bash
node build.js NDA_СтроимВместе_ИП_Орешкин.docx NDA_СтроимВместе_ИП_Орешкин.md
soffice --headless --convert-to pdf NDA_СтроимВместе_ИП_Орешкин.docx
```

## Что в документе

**Про данные и доступы (раздел 3).** Намеренно без перечня: состав определяется рабочей перепиской, по запросу и с разрешения компании. Новые доступы по ходу проекта не требуют ни приложения, ни допсоглашения (пп. 3.1, 3.3) — всё полученное автоматически попадает под режим NDA с момента получения. Обязуемся обращаться с доступами бережно: только для задач проекта, менеджер паролей, двухфакторка, не передаём никому кроме своей команды. Компания может отозвать доступы в любой момент. Если в чём-то откажет — это не нарушение, но и за результат в этой части мы не отвечаем (п. 3.2).

**Про инструменты (раздел 6).** Названы категории и конкретные сервисы: Claude, ChatGPT, Gemini, GigaChat, YandexGPT, Cursor, Claude Code, n8n, Make. Работаем на платных и API-тарифах с отключённым обучением на данных, в бесплатные и личные аккаунты ничего не грузим. ПДн в ИИ-сервисы не идут вообще. Особо чувствительное — только в российских сервисах или обезличенным. Расшифровка встреч — локально. По запросу за 5 рабочих дней даём перечень сервисов, компания может мотивированно потребовать замены.

**Про команду (раздел 4).** Раскрываем информацию своим людям без согласования и без списка. Названы роли, не фамилии. С каждого берём письменное обязательство о конфиденциальности, оно хранится у нас и компании не передаётся. Доступы отзываем за 3 рабочих дня после выхода из проекта. По мотивированному запросу подтверждаем количество и роли — без ФИО. Отвечаем за них как за себя, претензии компания шлёт только ИП.

**Про деньги (раздел 11).** Штраф 50 000 руб. за доказанный случай, зачётный. Совокупный потолок 100 000 руб. за всё время. Упущенная выгода, косвенные убытки и репутационный вред не возмещаются. За инциденты на стороне поставщиков сервисов не отвечаем, если сами раздел 6 соблюдали.

**Прочее.** П. 7.5 — заверение компании по ст. 431.2, что она вправе передавать данные и получила согласия по ПДн. П. 7.4 — трансграничной передачи нет. П. 5.3 — право использовать свои методики и общий опыт. П. 8.2 — портфолио без согласования, развёрнутый кейс по согласованию. П. 2.4 — нет эксклюзивности. Срок неразглашения 3 года.
